# V2 Customer Mockups

Created: 22 October 2026.

Status: Proposed visual concepts, not approved implementation targets.

V2 starts from scratch. These screens follow the locked product requirements and do not use the existing application as a design reference. Original direction: deep teal, terracotta, warm off-white, editorial headings, and spacious desktop layouts. All three flows are public; sign-in is optional. Images are static desktop concepts, not functional or responsive implementations.
